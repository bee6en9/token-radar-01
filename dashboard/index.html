Watchlist protocols, ranked by implied value

The watchlist is the floor: every protocol with at least $50M of TVL and no token on record. The early radar adds pre-token protocols below that floor. Implied value is a model, not a promise.

Reading it: Implied value is what a token would be worth if it launched, from the fitted size curve. Token odds is the chance it launches at all — a weak signal, read it as a tie-breaker. FARM means the expected airdrop, net of gas, clears $100 at $25 an hour with odds above the base rate; MARGINAL is worth watching; SKIP loses money on gas or is very unlikely to launch.     How implied value is computed

    One function scores every row from the snapshot figures. No protocol name is special-cased, and no row is hand-picked.

    Model constants (radar-3)
    ConstantValueWhat it means

    The size multiple is fitted, not assumed: log(market cap) = on the snapshot's launched tokens, so a bigger TVL implies a smaller multiple. Growth, maturity and breadth are fixed judgment terms from radar-2 — a richer model that fitted them made the held-out miss worse, so they stay fixed and the dashboard says so. Age is the time since the protocol was first listed, the best record of how long it has run with no token; an unlisted age uses 365 days. Breadth is the number of chains the protocol runs on: each extra chain up to five adds 3%. The product rule runs before ranking: exchanges, versioned pools, wrapped or staked products and exchange-branded products are out, because they are a token that already trades in another form. The early radar is every rankable pre-token protocol below the watchlist floor, by TVL, and the live-token protocols are set aside with their market caps shown.
